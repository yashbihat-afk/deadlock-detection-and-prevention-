THE CORE IDEA

Two ways to stay safe.

01 / DETECT

Find it after it happens.

Compare each process's outstanding request with the resources currently available. If no unfinished process can proceed, the remaining processes are deadlocked.

REQUESTi ≤ WORK → release ALLOCATIONi
02 / PREVENT

Break hold-and-wait.

Require a process to request its complete resource bundle while holding nothing. It either receives the entire bundle or waits without tying up resources.

HOLDING = 0 → request atomically
